# Data Cleaning and Preprocessing

## Project Overview
This project demonstrates how to clean and preprocess the Titanic dataset using Python. The dataset is cleaned by handling missing values, removing duplicate records, detecting and removing outliers, and saving the cleaned dataset for further analysis.

## Dataset
- Dataset: Titanic Dataset
- Source: Kaggle

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Steps Performed
- Loaded the Titanic dataset
- Checked dataset information
- Identified missing values
- Removed duplicate records
- Detected outliers using the IQR method
- Visualized outliers with a Box Plot
- Removed outliers
- Saved the cleaned dataset
